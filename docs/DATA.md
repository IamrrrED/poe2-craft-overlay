# Данные не поставляются с репозиторием / Data is not shipped with the repository

Публичный репозиторий содержит **только код** (MIT). Таблиц предметов, модов, весов и цен в нём нет: они
производные от чужих источников, и перепубликовать их — значит принять на себя их условия (GPL-3.0 у Path of
Building, данные GGG, условия poe.ninja). Поэтому данные **собираются локально** теми скриптами, что лежат в
`tools/`.

Результат: в репозитории нет ни одной строки третьих лиц — ни GPL-кода, ни дампа игры, ни снимка цен.

## Что нужно для локальной сборки данных

| Файл в `src/Data/` | Чем собирается | Откуда | Нужна сеть |
|---|---|---|---|
| `mods.lua`, `bases.lua` | `tools/extract_mods.py` | установленный Path of Building (Community) | нет |
| `coe_bases.lua`, `coe_mods.lua`, `coe_weights.lua` | `tools/fetch_coe_data.py` | Craft of Exile | да |
| `categories.lua` | `tools/fetch_categories.py` | торговый сайт (данные игры) | да |
| `desecrated.lua`, `desecration_pool.lua` | `tools/fetch_desecrated.py`, `tools/fetch_desecration_pool.py` | торговый сайт | да |
| `ru_bases.lua`, `ru_stats_*.lua`, `display_names_ru_*.lua`, `display_ru.lua` | `tools/fetch_ru_map.py`, затем `tools/build_display_names.py` | русский торговый сайт | да |
| `prices.lua` | `tools/fetch_prices.py` | poe.ninja | да |
| `icon_index.lua`, `currency_icons.lua` | `tools/fetch_icon_index.py`, `tools/fetch_currency_icons.py` | poe.ninja / официальные данные | да |
| `league_0_5_5.lua`, `config.lua`, `crafting_guide.lua` | **вручную, это наш текст** | патчноуты и наши правила | нет |

Порядок: сначала `extract_mods.py` (без него нет баз и модов), затем `fetch_coe_data.py`, `fetch_categories.py`,
`fetch_desecrated.py`, `fetch_desecration_pool.py`, `fetch_ru_map.py` + `build_display_names.py`,
`fetch_prices.py`, `fetch_icon_index.py`, `fetch_currency_icons.py`.

## Почему так

- **Path of Building — GPL-3.0.** Его таблицы нельзя раздавать под MIT; либо GPL на всё производное, либо не
  раздавать вовсе. Мы выбрали второе: код MIT, данные генерируются у пользователя.
- **Имена и тексты принадлежат Grinding Gear Games.** Инструмент использует их, чтобы показать предмет и найти
  его на трейде, но не переиздаёт каталог игры.
- **poe.ninja** не предназначен для перепубликации снимков; у нас цены и так обновляются из их API на месте
  (суточный кэш), поэтому поставлять `prices.lua` не нужно.

## Если данных нет

Движок скажет об этом прямо при первом запросе, а не будет молча показывать пустые моды. Для работы достаточно
прогнать генераторы один раз — дальше данные лежат локально и в git не попадают.

# English

The public repository contains **code only** (MIT). It does not contain the item, modifier, weight or price
tables: those are derived from other sources, and republishing them means accepting their terms (Path of
Building's GPL-3.0, GGG's game data, poe.ninja's terms). So the data is **assembled locally** by the scripts in
`tools/`.

The result: the repository holds no third-party content at all — no GPL code, no game dump, no price snapshot.

## What a local data build needs

| File in `src/Data/` | Built by | From | Network |
|---|---|---|---|
| `mods.lua`, `bases.lua` | `tools/extract_mods.py` | an installed Path of Building (Community) | no |
| `coe_bases.lua`, `coe_mods.lua`, `coe_weights.lua` | `tools/fetch_coe_data.py` | Craft of Exile | yes |
| `categories.lua` | `tools/fetch_categories.py` | the trade site (game data) | yes |
| `desecrated.lua`, `desecration_pool.lua` | `tools/fetch_desecrated.py`, `tools/fetch_desecration_pool.py` | the trade site | yes |
| `ru_bases.lua`, `ru_stats_*.lua`, `display_names_ru_*.lua`, `display_ru.lua` | `tools/fetch_ru_map.py`, then `tools/build_display_names.py` | the Russian trade site | yes |
| `prices.lua` | `tools/fetch_prices.py` | poe.ninja | yes |
| `icon_index.lua`, `currency_icons.lua` | `tools/fetch_icon_index.py`, `tools/fetch_currency_icons.py` | poe.ninja / official data | yes |
| `league_0_5_5.lua`, `config.lua`, `crafting_guide.lua` | **hand-written, our own text** | patch notes and our rules | no |

Order: `extract_mods.py` first (bases and modifiers depend on it), then `fetch_coe_data.py`,
`fetch_categories.py`, `fetch_desecrated.py`, `fetch_desecration_pool.py`, `fetch_ru_map.py` +
`build_display_names.py`, `fetch_prices.py`, `fetch_icon_index.py`, `fetch_currency_icons.py`.

## Why it is done this way

- **Path of Building is GPL-3.0.** Its tables cannot be redistributed under MIT; either everything derived becomes
  GPL, or nothing is redistributed. We chose the second: MIT code, data generated by the user.
- **Names and texts belong to Grinding Gear Games.** The tool uses them to show an item and find it in trade; it
  does not republish the game's catalogue.
- **poe.ninja** is not meant for snapshot redistribution, and prices are refreshed from their API on the spot (a
  daily cache), so shipping `prices.lua` is unnecessary.

## If the data is missing

The engine says so on the first request instead of silently showing empty modifiers. Running the generators once
is enough; the data then lives locally and never lands in git.
