# Тайник: что работает, а что нет — и почему

Всё ниже измерено на живом клиенте 0.5.5, а не выведено из документации.

## Что работает

| Действие | Как | Доказательство |
|---|---|---|
| Поднять игру вперёд | ALT-разблокировка + `SetForegroundWindow` | `PASS the game is in front` |
| Найти метку «Тайник» | нормализованная кросс-корреляция по кадру | `label at 634,404 (score 0.79)` |
| Открыть тайник | клик по найденной метке | `7.1 % пикселей изменилось` |
| Найти панель | поиск заголовка «Тайник» | `title at 370,104 (score 0.98)` |
| Переключать вкладки | клики по полосе под заголовком + проверка снимком | `tab 3 -> 20.0 % changed`, на кадре вкладка «Сучности» |

Кликаются **только метки объектов и вкладки**. Клик по сетке предметов запрещён: 25 октября 2026 такой клик взял
предмет, и второй клик, который должен был положить его обратно, чуть не уронил его на землю.

## Что не работает: чтение содержимого тайника через буфер обмена

**Измерено:** 60 наведений по панели вкладки, **0 прочитанных предметов**; прицельные наведения в известные
позиции предметов (49,225 / 180,230 / 300,250 / 120,340) дают **0 символов** в буфере, и на кадре после наведения
**подсказка не появляется**.

При этом в инвентаре тот же путь работает: зонд `--probe-capture` ловил реальный предмет («Разрушительное
проклятие», 1246 символов) с надетого слота.

Вывод: `Ctrl+C` в тайнике не копирует предмет, а наведение на ячейку тайника не открывает подсказку — значит и
читать нечего. Это ограничение игры, а не наша ошибка в координатах: сетка была заведомо перекрыта (панель
10,64 720×900, шаг 48).

## Значит для чтения тайника остаётся два пути

1. **OCR подсказок.** Навести на предмет, дождаться подсказки, распознать текст. Нужен движок OCR: в проекте его
   нет, у Python здесь только Pillow и numpy. Рабочий вариант — `Windows.Media.Ocr` (встроен в Windows 10+) через
   WinRT, но это новая зависимость и отдельная задача. Плюс: читает и тайник, и инвентарь. Минус: распознавание
   кириллицы в мелком шрифте — с ошибками, а ошибка в тексте предмета означает неверный совет.
2. **Читать только инвентарь** (это уже работает) и оставить тайник ручному выбору: игрок открывает вкладку,
   программа читает **инвентарь**, куда он перетащил интересные предметы.

## Что сделано в коде

- `overlay/StashOpener.cs` — открыть тайник по найденной метке, с проверкой снимком.
- `overlay/StashTabs.cs` — переключение вкладок с проверкой пикселями.
- `overlay/StashReader.cs` — перепись наведением (без кликов), с честным отчётом о покрытии.
- `tools/find_label.py` — детектор метки/заголовка (PIL + numpy, FFT-корреляция).
- `tools/grid_pitch.py` — замер периода сетки по кадру (экспериментальный: на практике ошибается, поэтому перепись
  работает без него).

## Ограничения, о которых надо помнить

- Шаблоны (`docs/stash-label.png`, `docs/stash-title.png`) — снимки интерфейса игры, в публичный репозиторий не
  попадают.
- `python` в системе оказался заглушкой Microsoft Store: настоящий интерпретатор передаётся через
  `POE2CRAFT_PYTHON`.
- Детектор ищет по снимку 2560×1440; при другом разрешении шаблон надо переснять (это минута).
