# Вкладки тайника: типы, форматы, как их читать

Источник: [Stash — Path of Exile 2 Wiki](https://www.poe2wiki.net/wiki/Stash) (зеркало
[poewiki.net/wiki/poe2wiki:Stash](https://poewiki.net/wiki/poe2wiki:Stash)) и
[PoE 2 Stash Tabs Explained (mobalytics)](https://mobalytics.gg/poe-2/guides/stash-tabs),
[Stash Tab Basics (maxroll)](https://maxroll.gg/poe2/news/the-fragment-tab-and-stash-tab-basics).

## Главное, что нужно алгоритму

| Тип вкладки | Формат | Что внутри |
|---|---|---|
| Обычная / Premium | **12×12** = 144 ячейки | любые предметы |
| Quad / Premium Quad | **24×24** = 576 ячеек | любые предметы |
| Currency | особые ячейки под каждую валюту (до 5000), 1 слот под предмет + 14 свободных | валюта |
| Essence | особые ячейки под каждую эссенцию (до 5000), 1 слот под предмет + 4 свободных | эссенции |
| Fragment | 6 под-вкладок по **8×12** | ключи, планшеты, ключи испытаний |
| Map | 6 под-вкладок на тир, по 96 Waystone (всего 576 на тир) | Waystone |
| Augment | особые ячейки (до 5000 каждой), группы: руны, руны Калгура, soul cores, идолы, древние аугменты | руны/аугменты |
| Delirium | особые ячейки (до 5000 каждого) | жидкие эмоции, осколки, Симулякр |
| Ritual | особые ячейки (до 5000 каждого омена) | омены, «Аудиенция у Короля» и др. |
| Breach | особые ячейки + 6 под-вкладок по **6×12** | катализаторы, осколки, камни Разлома, мешки |
| Expedition | особые ячейки (до 5000) | руны/сплавы/флюсы, логбуки, омены «Сага» |
| Gem | до 500 камней, сортировка по уровню/качеству | камни умений |
| Flask | до 500 фляг и оберегов | фляги |
| Unique | по одному каждого уникального предмета | уникумы |
| Merchant's | как обычная, для асинхронной торговли | предметы на продажу |

**Что это даёт:** для обычной вкладки геометрия известна точно — 12 столбцов и 12 строк. Значит, найдя на кадре
прямоугольник сетки, шаг ячейки = ширина/12 и высота/12, а центры ячеек — арифметика, а не догадка. Для
специализированных вкладок (валюта, эссенции, карты) такой равномерной сетки нет, и их читать «по клеткам»
неправильно: там ячейки привязаны к конкретным предметам.

## Список вкладок в интерфейсе

Вкладки видны **двумя** способами:

1. **Полоса сверху** панели — показывает несколько вкладок; если их больше, справа появляется **стрелка**,
   и полосу надо листать. Поэтому «прошёл по всем» по верхней полосе — неправда.
2. **Боковой список** справа от панели — перечисляет вкладки по именам (RITUAL, SOSO, MAPS, Сучности,
   FRAGMENTS, RUNES, EXPEDITION, RAZIUM, BEZDNA, DELIRIUM, GEMS, затем нумерованные 1…15). Он показывает больше
   вкладок сразу и позволяет переключаться по позиции, а не по стрелкам.

Для автоматизации боковой список удобнее: одна колонка, стабильные позиции, и каждый клик проверяется снимком.

## Как это влияет на чтение

- **Обычная вкладка:** сетка 12×12 → ячейки вычисляются; наведение по центрам, чтение `Ctrl+C`.
- **Quad:** 24×24 → шаг в два раза меньше.
- **Специализированные:** читать по ячейкам бессмысленно (ячейка = конкретный предмет, а не слот), поэтому для них
  либо распознавание подсказок (OCR), либо чтение только того, что игрок сам переложил в инвентарь.

## Ограничение, которое всё ещё в силе

Чтение тайника через буфер обмена **не работает** (измерено: 60 наведений → 0 предметов, прицельные наведения →
0 символов, подсказка не появляется). Поэтому геометрия 12×12 пока нужна не для чтения, а для **проверки**: когда
появится способ читать (OCR), ячейки уже будут известны.
