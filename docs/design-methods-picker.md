# Макет и план: «все способы крафта» вместо одного шага

Черновик по заявке заказчика. **Код не менялся** — это проект на утверждение.

## Что заказчик попросил

1. Программа работает в фоне, как сейчас.
2. По **Ctrl+Q** на предмете — собрать, **что вообще можно сделать с предметом в текущем состоянии**.
3. Показать поверх игры **ВСЕ доступные способы**, с группировкой по типу.
4. Пользователь **сам выбирает**, что крафтить; программа ведёт по этапам.
5. После выбора — сохранить **слепок** предмета.
6. Выполнил → подтвердил → снова Ctrl+Q → программа показывает, что стало лучше, а что можно **откатить**.
7. Ведёт до момента, когда крафтить уже нечего.

Уточнения из ответов: список модов нужен **широкий** (заказчик не знает заранее, что может выпасть);
фильтры — **поиск по тексту и по типу стата**; качество/Divine/Vaal — **отдельным блоком «улучшение»**;
подтверждение — **кнопкой «выполнено», затем Ctrl+Q**; делать **по этапам**, начиная с макета.

## Что уже есть в движке (проверено прогоном)

Это важно: **считать ничего нового не нужно**, всё это движок уже умеет.

| Данные | Состояние | Откуда |
|---|---|---|
| Пул модов способа с шансами | ✅ **готово** | `mod_chances`: для шлема ilvl 80 Exalted даёт 71 мод, у каждого `chance`, `tier`, `weightSource` |
| Пример строки | ✅ | `+(150-174) to maximum Life` · `chance=14.08` · `tier=4` · `weightSource=weights` |
| Точность весов | ✅ | `weightSource=coe` (точные, Craft of Exile) либо `weights` (оценка PoB) |
| Цепочки «омен + валюта» | ✅ | `omenOptions`: `Omen of Whittling + Chaos Orb`, `Sinistral Erasure + Chaos`, `Greater Exaltation + Exalted`, `Necromancy + Desecration Bone` |
| Эссенции / руны / катализаторы / жидкости | ✅ | `essence` в оменах, `runes.lua` (305), `catalysts`, `liquidEmotions` (26) |
| Слепок и сравнение | ✅ **есть** | `Craft/Memory.lua`: `mods()` + `compare()` + `fingerprint()`, уже считает «добавлено / убрано / изменилось» |
| Журнал шагов | ⚠️ **частично** | память хранит **один** шаг (файл `craft_memory.lua`), перезаписывается |
| Откат | ⚠️ **как данные есть, как совета нет** | правила знают `removes`/`removal` у Chaos, Annulment, `Omen of Whittling` |

## Экраны

Панель получает две новые вкладки к существующим «Шаг» и «Справочник».

### Экран 1. «Способы» — главное меню (новое)

Открывается кнопкой «Показать все способы» на вкладке «Шаг», либо сразу по Ctrl+Q (настраиваемо).

```
┌─ Ужасный нарост · Гремящий скипетр · Редкий · ilvl 78 ───────────────┐
│ Занято: 3 префикса, 2 суффикса · свободно: 0 префиксов, 1 суффикс    │
│ Дух: 114 · Дарует умение: Приспешник скелет-воин 18 ур.              │
├──────────────────────────────────────────────────────────────────────┤
│ ▼ ДОБАВИТЬ МОД (свободен суффикс)                                14   │
│     Exalted Orb            7,80 % · 1 exalted          ▸ 86 модов    │
│     Greater Exalted Orb    7,80 % · 40 exalted         ▸ 86 модов    │
│     Essence of …           гарантированно               ▸ 3 мода     │
│     Омен + валюта          21,35 %                      ▸ 86 модов   │
├──────────────────────────────────────────────────────────────────────┤
│ ▼ ЗАМЕНИТЬ МОД (слотов нет)                                      4   │
│     Chaos Orb              случайный мод → новый        ▸ 86 модов   │
│     Omen of Whittling      снимает мод с наименьшим ур. ▸ точно      │
│     Annulment              снимает случайный            ▸ 1 из 5     │
├──────────────────────────────────────────────────────────────────────┤
│ ▼ УЛУЧШИТЬ СУЩЕСТВУЮЩЕЕ                                          3   │
│     Armourer's Scrap       качество 0 % → 20 %          (не мод)     │
│     Divine Orb             переброс чисел               (не мод)     │
│     Руна / Soul Core       гарантированный мод           ▸ 3 мода     │
├──────────────────────────────────────────────────────────────────────┤
│ ▶ ОТКАТИТЬ ИЗМЕНЕНИЯ                                             2   │
├──────────────────────────────────────────────────────────────────────┤
│ ▶ РИСКОВАННОЕ (необратимо)                                       1   │
│     Vaal Orb               осквернение, может уничтожить             │
└──────────────────────────────────────────────────────────────────────┘
```

**Правила экрана:**

* В каждом блоке — **только то, что реально доступно сейчас**: нет свободного суффикса — нет блока
  «Добавить»; предмет освящён — нет «Откатить» и Vaal.
* У способа видно **шанс, цену и число модов** — как заказчик и просил: сначала «сколько всего», список
  по клику.
* `weightSource=coe` помечается зелёным «точные веса», `weights` — янтарным «оценка PoB»; где весов нет
  (сплавы, инстилляция, алтари) — **«шансы не считаются»**, без выдуманных чисел.
* Необратимое — **отдельным блоком**, а не в общем списке.

### Экран 3. Выбран способ — ведение по этапам (доработка существующего)

```
┌─ Выбрано: Omen of Whittling + Chaos Orb ─────────────────────────────┐
│ Шаг 1 из 3                                                           │
│  1. ✅ Качество до 20 % — Armourer's Scrap      [сделано]            │
│  2. ▶ Omen of Whittling в верстак, затем Chaos Orb                   │
│  3. ○ Vaal Orb — только если результат устраивает                    │
│                                                                      │
│ Снимает: 14 % увеличение духа (наименьший уровень)                   │
│ Даёт:    случайный префикс из 71 · целевой мод 9,20 %                │
│                                                                      │
│ [ Выполнено ]   [ Не получилось ]   [ Вернуться к способам ]         │
└──────────────────────────────────────────────────────────────────────┘
```

«Выполнено» **не заменяет** Ctrl+Q, а дополняет: по нажатию программа запоминает, какой шаг вы
подтвердили, а следующий Ctrl+Q показывает, что реально изменилось. Если изменилось не то, что ожидалось —
панель скажет об этом прямо, а не сделает вид, что всё по плану.

### Экран 4. «Журнал» — что изменилось и что можно откатить (новое)

Каждый захват добавляет запись; видно всю историю предмета.

```
┌─ Журнал предмета ────────────────────────────────────────────────────┐
│ 15:57  захват     3P/2S · нет качества · числа: дух 14, мана 52      │
│ 16:10  Armourer's Scrap   ✅ качество 0 % → 20 %                     │
│ 16:24  Chaos Orb          ⚠️ убран: +35 к максимуму маны             │
│                                добавлен: +18 % к сопротивлению холоду│
│ 16:31  Divine Orb         ✅ 14 → 15 % увеличение духа               │
├──────────────────────────────────────────────────────────────────────┤
│ ЧТО МОЖНО ОТКАТИТЬ СЕЙЧАС                                            │
│  • +18 % к сопротивлению холоду — снять Annulment (шанс 1 из 5)      │
│  • +3 к уровню камней приспешников — снять Omen of Whittling        │
│  • качество 20 % — вернуть нельзя                                    │
│  • числа после Divine — вернуть нельзя, только перебросить снова     │
└──────────────────────────────────────────────────────────────────────┘
```

**Что «откат» значит у нас и чего он значить не может.** Предмет в PoE2 уже изменён; вернуть его из
слепка нельзя. Поэтому откат — это **совет**: какие моды можно убрать, **чем именно** и с каким шансом, и
где откат невозможен (качество, освящение, осквернение, Divine). Это то, что заказчик и выбрал:
«показать, что можно убрать и чем».

## Модель данных

### Слепок (снимок предмета)

Расширяем существующий `Memory`: сейчас он хранит одну запись и перезаписывается.

```
snapshot = {
  at          = "2026-10-16 16:24:05",   -- время
  fingerprint = "v2|Sceptres|Rattling Sceptre|…|78",  -- что это за предмет
  mods        = { "+35 to maximum Mana [35]", … },    -- моды с числами
  quality     = 0,                        -- качество: отдельное число предмета
  implicit    = { "Grants Skill: …" },    -- свойства, не аффиксы
  action      = "chaos",                  -- что сделали перед этим захватом
  confirmed   = true,                     -- нажал ли пользователь «выполнено»
  split       = { prefixes = 3, suffixes = 2, openPrefixes = 0, openSuffixes = 1 },
}
```

Хранение: файл `src/craft_journal.lua` (список записей). **Переживает перезапуск панели** — сейчас
память одного шага теряется, а для «слепка» это уже важно.

### Журнал

Список слепков + вычисленная между ними разница тем же `Memory.compare`, что уже проверен тестами:
`added`, `removed`, `same`. Ничего нового считать не нужно.

### Доступные способы

Новая функция движка `Advisor.methods(item)`, которая собирает **один список** из того, что уже
разбросано:

| Блок | Источник | Состояние |
|---|---|---|
| Добавить мод | `rule.min/max` + `mod_chances` | готово |
| Заменить мод | правила Chaos/Annulment/Whittling | готово |
| Улучшить | `qualityStep`, Divine, руны | готово |
| Откатить | `removes` + `removal` у валют и оменов | данные есть |
| Рискованное | Vaal, освящение | готово |

## Что нужно доделать (по коду)

1. **Движок:** `Advisor.methods(item)` — свести в один список блоки, шансы, цены, число модов; помечать
   `oddsUnknown` там, где весов нет.
2. **API:** новый метод `craft_methods` (или расширить `analyze_item` полем `methods`).
3. **Панель:** вкладки «Способы» и «Журнал», поиск и фильтры, кнопки «Выполнено / Не получилось».
4. **Память:** журнал вместо одной записи, запись в файл, чтение при старте.
5. **Откат:** функция, которая по слепку говорит, какие моды снимаемы и чем.
6. **Сборка:** правки в `panel.html` требуют пересборки панели (копируется при сборке), Lua — только
   перезапуска.

## Этапы

| Этап | Что входит | Почему так |
|---|---|---|
| **1** | Экран «Способы»: блоки, шансы, цены, число модов; клик → список модов с поиском и фильтром по тегу; кнопки «Выполнено / Не получилось» | Даёт **основную ценность**: видно всё, что можно, и выбор за пользователем. Данные уже готовы |
| **2** | Журнал и слепки: запись в файл, история, «что изменилось» | Нужен фундамент для «лучше/откатить»; без него нечего сравнивать |
| **3** | Откат: какие моды снимаемы, чем и с каким шансом; пометка необратимого | Требует этапа 2 |
| **4** | Ценные моды сверху, сортировки по цене, предложение цепочек «добавить и заменить» | Улучшение поверх работающего |

## Ответы заказчика (зафиксированы)

1. **Окно**: передвигается, меняет размер, закрывается **только кнопкой**, всегда поверх игры.
   *Всё это уже сделано:* `FormBorderStyle.Sizable` (перетаскивание и размер), `TopMost = true`,
   `FormClosing` отменяется — панель только прячется, выход через трей.
2. **Строки**: выводить **все**, но в **свёрнутой группировке** и с бегунком: первые 20, остальные — при
   прокрутке. (Не «показать ещё» по кнопке, а подгрузка по мере прокрутки.)
3. **Сортировка**: переключаемая — по шансу / по ценности, и **по убыванию, и по возрастанию**.
4. **«Не получилось»**: показать **шансы на отмену** — каким способом можно освободить свойство
   (префикс/суффикс), даже если конкретно новый мод снять нечем.
5. **Цены**: сразу в **трёх валютах** (сфера возвышения, сфера хаоса, божественная сфера), **начиная с
   самой дешёвой**.
6. **Ctrl+Q** оставляем как есть — открывает «Шаг», а «Способы» доступны кнопкой. «Если что, поменяем».

## Что уже реализовано (этап 1, движок)

Инструмент `methods` собран и покрыт тестами; он же приложен к `analyze_item` полем `methods`, чтобы
панель делала **один** запрос на захват, а не два.

Проверено на скипетре заказчика:

```
== Добавить мод (6) ==
   Exalted Orb          mods=21  chance=7.8   цена: 1.3106 ex | 0.02 chaos | 0.0019 div
   ...
== Заменить или снять мод (4) ==
== Улучшить существующее (3) ==
== Рискованное (необратимо) (1) ==
```

Цены отсортированы **по возрастанию реальной стоимости** (проверяется тестом), список модов — **полный**
(21 мод, не «топ-5»), у каждого мода есть `text`, `tier`, `chance` и `weightSource`.

## Что ещё не сделано

Этапы 2–4 (журнал со слепками, откат, ценные моды сверху) — как в плане ниже.

## Чего у нас нет и что придётся честно помечать

* **Веса модов Waystone** — нет ни в PoB, ни в trade API. Панель скажет «шансы не считаются».
* **Рецепты инстилляции** (эмоции → нотабл) — данных нет. Способ будет в списке, но без разбивки по модам.
* **Сплавы** — пул есть, весов нет.
* **Ancient/Mythical руны** — в PoB их нет.
* **`Essence of the Abyss`** — нет в PoB (`missingEssences`).
* **Пул Колодца Душ из RePoE** — импортируется 0 модов, файл не подключён; см.
  `docs/data-inventory.md`. Очернение работает на словаре trade API + весах PoB.
