# Инвентаризация: какие проекты по PoE 2 у нас есть и что в них готово

Дата: сеанс после серии правок порядка шагов. Вопрос заказчика: «данные каких проектов по PoE 2 у нас
есть и каков статус их завершения». Ниже — **только проверяемые факты**: числа взяты из прогонов
генераторов и из самих таблиц, а не из памяти.

## Сводка по источникам

## 1. Path of Building — основной источник, готов

Прогон `python tools/extract_mods.py --verify` (2026-10-16):

```
mods:        9177 модификаторов из 6 файлов, групп 3596, уникальных текстов 3001
             непрочитанных раскладок: 0 (пропуски не выдумываются, а сообщаются)
runes:       305 рун в 21 слоте
runeforging: 496 базовых типов
bases:       1769 базовых типов
essences:    81
```

**Чего в PoB нет** (проверено, это не наша недоработка):

* **Ancient и Mythical руны** — их в `ModRunes.lua` нет вообще;
* **веса модов Waystone** — только описания статов, без `weightVal`;
* **`Essence of the Abyss`** — отсюда `missingEssences` в правилах;
* **рецепты инстилляции** — эмоции → нотабл отсутствуют.

## 2. Официальный trade API — готов

| Таблица | Объём | Что покрывает |
|---|---|---|
| `categories.lua` | `baseCount = 3129` | класс предмета как его видит сама игра (второе мнение после PoB) |
| `desecrated.lua` | `count = 749` | официальный словарь десекрейта, en + ru |
| `ru_bases.lua` | `count = 3128` | русские названия баз |
| `ru_stats*.lua` | **3 084** (3 021 explicit + 57 implicit + 6 enchant) | русские статы → английские, по id |

**Фактическое покрытие перевода — частичное** (проверено на строках реального шкипетра):

| Русская строка | Перевод |
|---|---|
| `37(33-38)% увеличение энергетического щита` | ✅ `increased Energy Shield` |
| `+32(27-32) к максимуму маны` | ✅ `to maximum Mana` |
| `+3 к уровню всех камней умений приспешников` | ✅ `Level of all Minion Skills` |
| `16(15-18)% повышение редкости найденных предметов` | ✅ `increased Rarity of Items found` |
| `14(10-14)% увеличение духа` | ❌ не переводится |
| `15% снижение требований к характеристикам` | ❌ не переводится |
| `Союзники в вашем присутствии наносят увеличенный на 31(25-34)% урон` | ❌ не переводится |

Причина: словарь покрывает **фильтры торгового сайта**, а не все формулировки модов PoB. Сторону и тир
это больше не ломает — их даёт разметка игры (`{ Префикс … (Уровень: N) }`), см.
`docs/SESSION-HANDOFF.md`. Но у непереведённых строк **не определяется тир**, и панель честно помечает
их как неизвестные.

## 3. Craft of Exile — подключён, это лучший по точности источник

`src/Data/coe_weights.lua`: `types = 1346`, `tiers = 19332`, и **все 19 332 строки несут вес**
(проверено). Именно отсюда берётся маркер достоверности `weightSource = 'coe'` — «точные веса», в
отличие от `weights` — «оценка PoB». В панели это показано зелёным и янтарным соответственно.

## 4. poe.ninja — снимок устарел

`prices.lua`: `currencyCount = 402`, `league = "Forbidden Rites"`, `fetchedAt = "2026-10-06 23:17"`.
`icon_index.lua`: 434 предмета с иконками. **Снимку около недели**, автоматического обновления нет —
есть только генераторы `tools/fetch_prices_ninja.py`, `fetch_prices_official.py`, `fetch_all_icons.py`.

## 5. RePoE-fork — единственный провал по данным

Прогон `python tools/fetch_desecration_pool.py`:

```
desecration mods in the datamine: 0
eligible for tags ['armour','helmet','default'] at item level 79: 0
acceptance: NOT PASSED
  MISSING from the pool: desecrated.stat_3299347043 (# to maximum Life)
```

То есть в текущей выгрузке RePoE **ни один мод не помечен как desecrated** — пул Колодца Душ из неё не
собирается. Что при этом важно:

* `desecration_pool.lua` (160 КБ) **не подключён к движку вообще** — ни одного `require` на него нет;
* очернение работает на **других** данных: словарь `desecrated.lua` + веса из `mods.lua` по тегу
  `breach_desecration`;
* модель раскрытия «3 из пула» уже реализована и **проверена построчно** против чужой чистой функции
  (`tools/gen_reveal_reference.py` → `src/Tests/reveal_reference.lua`, 76 строк, точность 1e-9).

**Вывод: файл мёртвый, генератор даёт ноль.** Либо находим источник с настоящими весами, либо удаляем
файл и генератор, чтобы не выглядело как работающее покрытие.

## 6. poe2wiki — точечный скрейп, не система

`poe2/` в корне воркспейса: `essences.txt` (73 КБ), `essences_summary.txt`, `hysteria.html`,
`essence_page.html` + скрипты `scrape.ps1`, `summarize.ps1`. Это разовая выгрузка под конкретный вопрос,
а не поддерживаемый источник. В `poe2craft/` не входит и в движке не используется.

## 7. Чужие проекты крафта — прочитаны, не запущены

* **`poe2-crafting-mcp`** (2,1 МБ, Python ~15 тыс. строк + Rust-крейт): требует Nix (`flake.nix`),
  которого в системе нет, поэтому **чтение кода, а не прогон**. У них **своя SQLite-база** (17 пулов,
  скрейп), у нас — таблицы PoB. Очернение они моделируют как «3 из пула» — **эту формулу мы переняли и
  проверили**. Их `data/poe2_craft.db` в клоне пустая (только `-shm`).
* **`poe2-mcp` (★82)** в `vendor/mcp-probe`: установлен в venv, диагностирован — не отвечает на
  `initialize` даже за 540 с. Числовое сравнение сделано через их чистую функцию вероятности.

## Что из этого следует (по приоритету)

1. **Удалить мёртвый `desecration_pool.lua` и его генератор** — сейчас это 160 КБ и `count = 0`,
   которые выглядят как покрытие. Очернение и так работает на `desecrated.lua` + `mods.lua`.
2. **Обновить снимок цен** (недельной давности) или сделать его обновляемым по кнопке.
3. **Починить перевод русских формулировок** — самый заметный пробел для игрока на русском клиенте:
   три из семи проверенных реальных строк не опознаются, и у них нет тира.
4. **Источник Ancient/Mythical рун и рецептов инстилляции** — в PoB их нет; нужен внешний источник,
   иначе эти механики останутся непокрытыми честной пометкой.
5. **Провенанс PoB**: клон shallow, таблицы сняты с dev-ветки без релиза — для воспроизводимости нужен
   полный клон и сверка по дате.
